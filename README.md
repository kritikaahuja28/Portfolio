# Portfolio

Personal portfolio of **Kritika Ahuja**, GenAI Engineer at EY-GDS.

A static site (HTML, CSS, vanilla JS) with sections for About, Experience, Services, Projects, Skills, Blogs and Contact. It follows the system light/dark setting and works on mobile.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```
